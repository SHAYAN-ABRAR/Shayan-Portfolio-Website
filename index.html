LunarLab — Reward Design Lab for RL

Solo build · 38 trained agents, 3,800 held-out test flights

A reinforcement-learning lab that measures what happens when an AI is rewarded for the wrong thing. Agents learn to land a rocket under different reward designs; one flawed bonus teaches them to hover instead, and they land in 0 of 500 test flights. Includes PPO vs DQN comparisons, rewards learned from simulated preference labels, 3D flight replay, and CI on Linux and Windows.

Python PyTorch Stable-Baselines3 React Three.js
Live Demo GitHub

Retinal Foundation Model Study

Research code · 110 runs, 134 GPU-hours, 438 tests

Asks whether a quick frozen test of a medical AI model predicts how it performs after full fine-tuning. I compared RETFound, a retinal foundation model, with the ImageNet model it was built from, on diabetic-retinopathy datasets held out from training. On two held-out datasets, the ImageNet model's large lead under the frozen test shrank by about 0.10 QWK after full fine-tuning. Manuscript in preparation.

Python PyTorch Scikit-learn pytest
